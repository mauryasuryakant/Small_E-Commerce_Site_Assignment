# Authentication & Product CRUD APIs

This project is part of an **assignment from Sheryians Coding School**.

The purpose of this project is to implement a small full-stack application with:

* JWT authentication using access and refresh tokens
* Product CRUD APIs
* Request validation using `express-validator`
* A React frontend to consume the APIs

## Tech Stack

**Backend:** Node.js, Express, MongoDB, JWT, bcrypt, express-validator

**Frontend:** React, Redux, Axios, Tailwind CSS
